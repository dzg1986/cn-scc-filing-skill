# 个人信息出境标准合同备案技能包

把业务咨询里最常被问的那些问题——"我们这种情况要不要备案""材料到底要哪些""大湾区合同和一般合同怎么选""被退回怎么补"——做成一个可以装进 AI 里的技能。
装上之后，描述你的场景，它会给出：走哪条通道、依据哪一条、材料清单、流程时限、最容易卡的三个点。

- 覆盖两条通道：**一般标准合同备案**（省级网信部门）与**粤港澳大湾区标准合同备案**（广东省网信办，内地九市 ↔ 香港/澳门）
- 内容来源：根据业务咨询整理（2025 年 10 月—2026 年 10 月）+ 现行法规原文
- 作者：**丁振赣 律师**（广东广和律师事务所）　最后更新：2026-11-10　版本：v1.0.0

---

## 它解决什么问题

标准合同备案的门槛不在"懂法条"，在"知道实务上怎么收件"。
同一个问题——"员工信息传给香港母公司要不要备案"——答案取决于：是不是湾区内部流动、有没有集体合同、敏感信息多少人、接收方在哪注册。这些判断散在四部法规、两份湾区指引、一份备案指南和大量实务口径里。
这个技能把"判断 → 材料 → 流程"压成一次问答，并且**每一条结论都带条号或明确标注"业务口径"**。

## 三种安装方式

### 方式一：上传技能包（推荐，最稳）
1. 下载本仓库（`Code` → `Download ZIP`），解压
2. 解压后会多一层 `cn-scc-filing-skill-main/`，进去找到 `skills/cn-scc-filing/` 这个文件夹
3. 打开支持技能（Skill）的 AI 客户端（如 WorkBuddy、扣子 Coze；豆包 App 本身没有技能上传入口）
4. 进入「技能 / Skills」→ `+ 添加` → **上传技能** → 把 `cn-scc-filing` 整个文件夹拖进去
5. 在对话框输入 `/` 或 `@` 选择本技能，或直接描述场景（会自动匹配）

### 方式二：对话创建
1. 打开 `skills/cn-scc-filing/SKILL.md`，全选复制
2. 在 AI 客户端新建技能，粘贴为指令，名称填「个人信息出境标准合同备案」
3. 把 `references/` 下 8 个文件作为知识文件一并上传（如有该功能）

### 方式三：企业后台统一下发
企业管理员在后台把本技能上传为「企业技能」，按成员范围配置，员工打开即可用，无需自行安装。

### 方式四：Claude Code / 本地 Agent
把 `skills/cn-scc-filing/` 整个文件夹复制到对应客户端的技能目录：

| 客户端 | 放到哪里 |
| --- | --- |
| Claude Code | `~/.claude/skills/`（全局）或项目下 `.claude/skills/` |
| DeepSeek Harness | 工作区下的 `.dsh/skills/`（注意是隐藏目录，不是 `skills/`） |
| 其他本地 Agent | 以其文档说明的技能目录为准 |

放好后重启客户端，技能才会被扫描到。**验证方法**：新开一个会话，问它"你有哪些可用技能"，清单里应出现 `cn-scc-filing`。

> 上架到不同平台要补的东西：WorkBuddy 开放平台需补 display_name、display_name_en、description_zh、description_en、version、author 六个字段；扣子（Coze）上传 zip 后会重新打包，改了内容必须重传。

```
cn-scc-filing-skill/
├── skills/
│   └── cn-scc-filing/
│       ├── SKILL.md                     ← 主文件：五步工作流、输出格式、边界、正反例
│       └── references/                  ← 按需加载的知识文件
│           ├── 01-routing.md                  前置判断：是不是出境、要不要备案
│           ├── 02-thresholds-and-exemptions.md 三档门槛 + 五类豁免 + 易错点
│           ├── 03-scc-general.md              一般标准合同：材料、流程、五个高频错误
│           ├── 04-scc-gba.md                  大湾区标准合同：资格、材料、双方备案
│           ├── 05-timeline.md                 时限与办理周期
│           ├── 06-faq.md                      70 条真实咨询整理（A—G 组）
│           ├── 07-rejected-and-boundary.md    退回原因、补正、答复边界
│           └── 08-law-index.md                法规条文索引与易混淆点速查
├── scripts/
│   └── qa_check.py                ← 发布前自检：结构 / 规范 / 覆盖度 / 脱敏
├── docs/
│   ├── 使用说明.md
│   └── 口径来源与更新方法.md
├── CHANGELOG.md
└── LICENSE
```

**为什么拆成多个文件**：SKILL.md 只放"怎么干活"；条文、材料清单、70 条问答放 `references/` 按需加载。技能本体保持轻量，知识可以独立更新。

## 数据来源与脱敏

全部案例来自真实业务咨询，但**已做三层脱敏**：

1. 企业名称、联系人、联系电话、受理人 —— 原始记录中即已清空
2. 行业描述只保留判断所必需的必要条件（如"医疗""电力"），不保留地域与企业特征组合
3. 不设可回溯编号；案例编号（Q-A01 等）为分类编号，不指向任何真实主体

详见 `docs/口径来源与更新方法.md`。
