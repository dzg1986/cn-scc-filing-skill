# 使用说明（给第一次用的人）

## 一句话
把你的情况说清楚，它告诉你要不要备案、走哪条通道、材料要哪些、多久能办完。

## 怎么问效果最好

按这六项说，越具体越准：

1. **主体在哪儿**：注册地（是否湾区内地九市、是否自贸区/河套）、是不是关键信息基础设施运营者
2. **传什么**：姓名、电话、身份证号、健康/医疗、生物识别、金融账户、行踪轨迹、基因测序……（有没有敏感个人信息）
3. **传多少**：当年累计多少人、其中敏感个人信息多少人
4. **传给谁**：境外母公司、客户、物流商、SaaS 服务商？在哪个国家/地区？会不会再转给第三方
5. **为什么传**：人事管理、客服、物流履约、研发、营销、履行合同
6. **流动方向**：内地↔香港/澳门（湾区通道）？还是内地↔其他国家（一般通道）

## 例子

> 我们在深圳，把员工姓名、身份证号、薪酬传给香港母公司做人事管理，今年累计 300 人，会不会再转给其他地区不清楚，要走什么手续？

## 它会给什么

- 通道结论（免申报 / 一般标准合同 / 大湾区标准合同 / 安全评估 / 认证 / 不属于出境）
- 依据（法规名 + 条号，或明确标注"业务口径"）
- 材料清单（按阶段，标必备/视情况）
- 流程与时限
- 这个场景最容易卡的三个点

## 什么时候它不会答

- 重要数据是否成立的实质认定
- 已被约谈、检查、要求整改
- 要求出具书面认定、预测通过率
- 要求"怎么少报""怎么拆数量"
- 外国司法或执法机构调取数据
- 不属于数据出境的咨询（App 功能、网络许可、工商登记）

遇到这些它会让你找主管部门或律师。这是刻意设计的边界，不是它不会。

## 三个提醒

1. 它讲的是**政策与流程**，不是替你签字的法律意见。
2. **时限是查验时限，不是全部办理时间**——前面还有合同签署、PIA、材料准备。
3. 法规和业务口径会变。仓库里 `CHANGELOG.md` 会记录变更，用之前看一眼版本日期。
