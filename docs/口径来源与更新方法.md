# 口径来源与更新方法

## 一、内容从哪来

| 来源 | 用途 | 处理方式 |
|---|---|---|
| 数据合规业务咨询记录（2025-10 至 2026-10） | 高频问题、实务口径、材料细节 | 归纳去重后改写为结构化问答；三层脱敏（见下） |
| 《促进和规范数据跨境流动规定》等现行法规原文 | 条文引用 | 逐条摘录，标注生效日期 |
| 《粤港澳大湾区个人信息跨境流动标准合同备案指南》及两份实施指引 | 大湾区通道材料与流程 | 引用规则要点，不虚构条号 |
| 技术标准（GB/T 43697、TC260-PG-20244A 等） | 重要数据、敏感个人信息识别 | 仅给指引，不做个案认定 |

## 二、脱敏规则（硬约束）

发布前必须逐项确认：

1. **四类字段清空**：企业名称、联系人姓名、联系电话、受理人。
2. **不做特征组合**：行业 + 地域 + 时间 + 规模四项不能同时出现。例如"深圳某碳资产企业 2025 年 10 月咨询"这类组合不可保留，只能保留判断所必需的"碳资产类数据"。
3. **不设可回溯编号**：不使用原始记录行号；问答编号（Q-A01 等）为分类编号，不对应任何真实记录。
4. **不写具体联系方式**：涉及咨询渠道的，统一写"属地网信部门公布的数据跨境咨询渠道"。
5. **金额、人数只保留判断必需的量级**（如"1000 人以内""约 300 人"），不保留精确可识别的数字组合。

发布前自检命令（任选其一）：

```bash
grep -rnE "1[3-9][0-9]{9}|0[0-9]{2,3}-?[0-9]{7,8}|@[a-z]+\.[a-z]+" .
grep -rnE "有限(公司|责任公司)|股份有限(公司)|集(团)|银(行)|医(院)" .
```

命中即拦截，不得发布。

## 三、更新方法

法规或口径变化时，按以下顺序改，避免改漏：

1. 先改 `references/08-law-index.md`（条文底座）
2. 再改 `references/02-thresholds-and-exemptions.md`（门槛与豁免）
3. 再改 `references/03-scc-general.md` / `04-scc-gba.md`（材料与流程）
4. 再补 `references/06-faq.md`（新增问答）
5. 最后改 `SKILL.md` 的"时效声明"与 `CHANGELOG.md`

### 三个必须定期复核的点（变化最快）

- 大湾区备案是否仍为线上受理（2025-12 起为线上）
- 各省备案材料清单差异（本仓库以广东/深圳口径为主）
- 自贸区负面清单是否调整（河套、前海等）

### 复核节奏建议

- 每季度一次例行复核
- 出现以下信号立即复核：新办法施行、备案系统改版、业务答复口径与本文不一致、用户反馈答错

## 四、反馈与纠错

发现答错，请提交 Issue 并附：问题原文、期望答案、依据（条号或业务答复）。核实后进入下一版，并在 CHANGELOG 记录。
