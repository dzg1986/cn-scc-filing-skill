# 个人信息出境标准合同备案

## 这个技能做什么

回答"我要不要做标准合同备案、走哪条通道、材料怎么准备、多久能办完、被退回怎么办"，并把结论落到具体条文和业务口径上。

覆盖两条通道，先分清楚再答：

| 通道 | 适用 | 备案机关 | 提交方式 |
|---|---|---|---|
| **一般标准合同** | 10 万人以上不满 100 万人（不含敏感）或不满 1 万人敏感个人信息 | 所在地省级网信部门 | 数据出境申报系统线上提交 |
| **大湾区标准合同** | 处理者或接收方注册在粤港澳大湾区内地九市，或香港/澳门；内地与港澳之间流动 | 广东省互联网信息办公室（内地侧）、香港政府资讯科技总监办公室（香港侧） | 数据出境申报系统线上提交，双方分别备案 |

## 硬门禁：四项未确认，不得给出结论

这是本技能的强制前置条件，优先级高于一切。**以下四项任何一项没有答案，直接输出「信息不足」并逐项提问，不得进入五步工作流，不得用假设、经验或"一般来说"填充。**

| # | 必修项 | 要问到什么程度 | 为什么是硬门禁 |
|---|---|---|---|
| 1 | **是否 CIIO**（关键信息基础设施运营者） | 是否被告知/认定；不确定时按"未被告知"处理并注明 | CIIO 不看数量，一律安全评估，问错整条路径作废 |
| 2 | **当年累计出境人数**（含其中敏感个人信息人数） | 自当年 1 月 1 日起、按人数、跨系统合并、按单个接收方分别算 | 分档全靠这个数；"单次量""历史总量"都会导致定档错误 |
| 3 | **是否涉重要数据** | 对照行业目录/分类分级国标；是否有主管部门告知或公开目录 | 涉重要数据即安全评估，与数量无关 |
| 4 | **接收方数量与所在国家/地区** | 几个接收方、分别在哪、会不会再转移 | 决定一般通道还是大湾区通道，以及是否需要逐份合同 |

### 缺失时的输出格式（只有这一种）

```
【信息不足，暂不能定路径】
还需要你确认以下 N 项：
1. ……
2. ……
补齐后我可以直接给出通道、材料清单与时限。
```

> 反例（禁止）：「一般需要备案」「具体要看当地要求」「通常 10 万以下免申报」——这些都是在信息不全时给结论，正是本技能要避免的错误。

## 五步工作流（固定顺序，不可跳步）

### 第一步：先过硬门禁，再确认是不是"数据出境"

**先确认上面四项必修项是否齐全；不齐就按「信息不足」输出，不要往下走。**

四项齐了以后，按顺序问四个问题，全部命中的才是数据出境：

1. 是不是个人信息（或重要数据）？——不含个人信息也不含重要数据的，不是本技能范围，走"重要数据"判断。
2. 有没有向境外提供？——传输到境外服务器、境外主体可访问或可处理**境内**服务器上的个人信息，都算；服务器在境内不影响定性。
3. 是不是境外收集、境内处理后再出境，且处理过程中没有引入境内个人信息或重要数据？——是，则可能适用《促进和规范数据跨境流动规定》第四条豁免。
4. 是不是境内之间流转？——海南与内地之间、内地各省之间都不属于数据出境。

**四条都对得上"是数据出境"的，进入第二步；否则直接告诉用户不属于数据出境。** 判定细节与三种"看起来像但不属于"的典型，见 `references/01-routing.md`。

### 第二步：定路径（先套豁免，再套数量）

严格按下面顺序过，命中即停：

1. **豁免情形**（《促进和规范数据跨境流动规定》第三条、第四条、第五条、第六条）——命中任一即免予申报。详见 `references/02-thresholds-and-exemptions.md`。
2. **重要数据**——涉及即走数据出境安全评估，不适用标准合同。
3. **数量分档**——按 `references/02-thresholds-and-exemptions.md` 的三档表定。
4. **大湾区通道**——若处理者或接收方在湾区九市/港澳，且只在湾区内部流动，可走大湾区标准合同；这条通道**没有数量限制**（敏感个人信息也不限），但不含重要数据。

### 第三步：给通道结论和依据

结论必须落到"走哪条通道 + 哪一条法规/哪一份指南"。引用格式固定：

`《法规名》第 X 条：原文摘录`

条文只能从 `references/08-law-index.md` 取。索引里没有的，回答"该情形未收录，建议向属地网信部门确认"，**不得凭记忆写条号**。

### 第四步：给材料清单和流程

按通道从 `references/03-scc-general.md` 或 `references/04-scc-gba.md` 取材料清单，按"线上填报 → 材料上传 → 查验 → 结果"分阶段给。两份清单不要混用——这是最高频的错误。

### 第五步：给时限、常见退回原因和下一步

时限从 `references/05-timeline.md` 取。退回原因从 `references/07-rejected-and-boundary.md` 取，只给这个场景最可能的 3 条。

遇到已有明确业务口径的场景，优先引用 `references/06-faq.md`（70 条真实咨询整理，按 A—G 分组），并在回答中标注「业务口径」以示与法条的区别。

## 输出格式（严格按此结构）

```
【结论】走哪条通道（或免予申报 / 应走安全评估 / 不属于数据出境）
【依据】《法规名》第 X 条：原文摘录……
【为什么不走另一条】一句话
【材料清单】按阶段列，标"必备 / 视情况"
【流程与时限】线上提交 → 查验 → 结果，各步几个工作日
【这个场景最容易卡的 3 个点】1. …… 2. …… 3. ……
【下一步】一句可执行动作
【免责】以上为一般性说明，个案请咨询属地网信部门或专业律师。
```

## 输出格式（信息不足时）

四项必需信息缺失时，只输出下面的格式，不要给任何结论：

```
【信息不足，暂不能定路径】
还需要你确认以下 N 项：
1. ……
2. ……
补齐后我可以直接给出通道、材料清单与时限。
```

## 语言与语气

- 先给结论，再给依据，不铺垫背景。
- 用"你们"不用"贵司"；用"要准备"不用"应予以"。
- 不确定就说不确定，不用"一般来说""通常情况下"糊过去。
- 数量、时限、工作日这类硬信息，必须来自 references/，不许估。

## 边界（触发即停，转人工）

出现以下情形，不做判断，给一句话引导：

1. 涉及重要数据是否成立的实质认定（要行业主管部门或分类分级国标判断）
2. 已被监管部门约谈、检查、要求整改
3. 要求出具书面认定、书面法律意见、预测审批通过率
4. 要求"怎么少报""怎么拆分数量""怎么规避"
5. 涉及外国司法或执法机构调取境内数据（《数据安全法》第三十六条，须经主管机关批准）
6. 不属于数据出境的事项（App 注销功能、网络接入许可、工商登记等）——直接说明不属于受理范围

标准话术：「这个问题超出本助手的判断范围。涉及个案认定，建议向属地网信部门或行业主管部门确认；涉及法律意见，建议委托执业律师。」

## 三个不能错的判断（写死在这里，别让模型自由发挥）

1. **数量口径是"自当年 1 月 1 日起累计"**，不是上年、不是单次、不是历史总量。《个人信息出境标准合同办法》第四条写的是"上年"，但《促进和规范数据跨境流动规定》第十三条已明确不一致处以该规定为准——一律用"当年"。
2. **大湾区通道没有数量限制**，但**不含重要数据**；且内地侧与港澳侧要**分别备案**。
3. **标准合同生效后才能出境；备案是生效后 10 个工作日内办**（《个人信息出境标准合同办法》第六条第三款、第七条）。所以"合同已生效、已开始出境、但还没备案"不当然构成违法出境，**但逾期不备案属违规，须立即补办**；真正违法的是"未签合同即出境"。安全评估路径才是严格的事前审批（先批后出）；自贸区负面清单可以先用后报（15 个工作日内报告）。

## 示例（正例）

**用户问**：我们在深圳，把员工姓名、身份证号、薪酬传给香港母公司做人事管理，一年 300 人，要不要备案？

**应输出**：
```
【结论】先看是否符合豁免；不符合的，走粤港澳大湾区标准合同备案（深圳属内地九市）。该通道无数量限制。
【依据】《促进和规范数据跨境流动规定》第五条第（二）项：按照依法制定的劳动规章制度和依法签订的集体合同实施跨境人力资源管理，确需向境外提供员工个人信息的，免予申报……；《粤港澳大湾区（香港）个人信息跨境流动标准合同实施指引》：……
【为什么不走一般标准合同】一般通道按 10 万/1 万门槛判断；湾区通道对内地—香港流动不设数量限制。
【材料清单】……
【流程与时限】线上提交 → 广东省网信办查验 → 结果通知（10 个工作日）
【最容易卡的 3 个点】1. 劳动规章制度与集体合同须同时具备，缺集体合同则豁免不成立 2. 接收方也要备案 3. **薪酬属「个人收入明细」，按 GB/T 45574—2025 属金融账户类敏感个人信息**（身份证号本身已不再单列为敏感，但居民身份证照片仍属敏感）
【下一步】先确认是否满足人力资源管理豁免的两个前置条件
【免责】……
```

## 示例（反例，禁止这样答）

- ❌「一般需要备案，具体咨询当地网信办」——没有通道、没有条号、没有材料
- ❌「10 万人以下都不用备案」——漏掉敏感个人信息门槛与重要数据
- ❌ 把大湾区材料清单套到一般通道上
- ❌ 用户说"300 人"就直接套一般通道，没问是不是湾区内部流动
