# 01 前置判断：是不是数据出境、要不要备案

> 用法：按顺序四问，答完再进入路径判断（02）。任何一问没问清，先问，不要猜。

## 四问

### 问 1：涉及的是不是个人信息或重要数据？

- 是个人信息 → 继续
- 是重要数据（或可能构成）→ 走数据出境安全评估，不适用标准合同
- 都不是（纯企业数据、公开工商信息、产品参数、建筑图纸、设备外观等）→ 不属于本技能范围，提示"按重要数据标准自查后可自由流动"

判定提示：
- 匿名化后无法识别特定自然人且不能复原的，不属于个人信息
- 企业客户的工商登记信息、业务数据，通常不属于个人信息（但要查是否含联系人姓名、手机号）
- 敏感个人信息（健康、生物识别、金融账户、行踪轨迹、不满十四周岁未成年人信息等）按 TC260-PG-20244A《网络安全标准实践指南—敏感个人信息识别指南》识别

### 问 2：有没有"向境外提供"？

构成出境的情形（只要命中一种就算）：
- 直接传输至境外服务器
- 境外主体可以访问、下载、处理存储于**境内**服务器上的个人信息
- 通过邮件、即时通讯、共享白板等方式让境外主体看到
- 委托境外供应商处理（含 SaaS、云服务、客服外包）

**不构成出境**：
- 海南 ↔ 内地之间的数据传输（海南属境内）
- 内地省际之间流转
- 港澳台用户在境内平台查看**境内**已公开信息且不涉及境外主体处理

### 问 3：是不是"境外收集—境内处理—再出境"？

《促进和规范数据跨境流动规定》第四条的例外：在境外收集和产生的个人信息传输至境内处理后再向境外提供，**处理过程中没有引入境内个人信息或重要数据**的，免予申报。

要点：必须同时满足"境外收集"+"未引入境内信息"。如果处理过程中混入了境内用户的数据，就不适用。

### 问 4：是不是境内之间流转？

- 海南、内地各省之间 → 不是出境，结束
- 涉及港澳台 → 是出境

## 判定树

```
Q1 是否涉及个人信息或重要数据？
  ├─ 否 → 不是本技能范围（重要数据另走安全评估）
  └─ 是 ↓
Q2 是否向境外提供？
  ├─ 否 → 不是数据出境
  └─ 是 ↓
Q3 是否符合《促进和规范数据跨境流动规定》第三/四/五/六条豁免？
  ├─ 是 → 免予申报（仍要履行告知、单独同意、PIA 等义务）
  └─ 否 ↓
Q4 是否涉及重要数据？
  ├─ 是 → 数据出境安全评估
  └─ 否 ↓
Q5 处理者或接收方是否在湾区九市 / 港澳？
  ├─ 是，且只在湾区内部流动 → 大湾区标准合同备案（无数量限制）
  └─ 否 ↓
Q6 数量落在哪一档？（见 02）
  ├─ ≥100 万人（非敏感）/ ≥1 万人敏感 → 数据出境安全评估
  ├─ 10 万—100 万人（非敏感）/ <1 万人敏感 → 一般标准合同 或 认证
  └─ <10 万人（非敏感）→ 免予申报
```

## 三种"看起来像但不属于"的典型

| 场景 | 判断 | 说明 |
|---|---|---|
| 境外用户在境内平台查看境内信息 | 不是出境 | 数据处理仍在境内 |
| 港澳用户登录境内 App 查看自己账户 | 一般不是出境 | 但若境外主体参与处理则另论 |
| 纸质材料带出境 | 可能是出境 | 含个人信息或重要数据时，与电子数据同一路径 |
| 跨境专线/运营商通道 | 只是传输方式 | 不改变是否出境的定性 |
